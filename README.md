# mold_agent

mold_agent — A Python retrieval-augmented agent framework for building modular RAG agents that combine document retrieval and LLM-powered workflows.

特性
- 组合文档检索与大模型，构建可插拔的 RAG agent

快速开始
1. 克隆仓库
2. 复制并重命名 `.env.example` 为 `.env`，填写私密配置
   ```bash
   cp .env.example .env
   ```
3. 安装依赖
   ```bash
   pip install -r requirements.txt
   ```
4. 运行
   ```bash
   python main.py
   ```

环境变量
- 请勿把 `.env` 提交到仓库。项目根目录包含 `.env.example`，用于说明需要哪些变量。
